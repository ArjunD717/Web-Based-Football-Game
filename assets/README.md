# Character and environment assets

## Player asset

`characters/player-01.glb` is **Avery Cole**, a fictional Northbridge Athletic
number 9. It is a self-contained glTF 2.0 binary with embedded WebP textures.
`characters/player-01-match.glb` is the match-only LOD derived from it.

| Item | High-detail lab asset | Match LOD |
| --- | ---: | ---: |
| File | `characters/player-01.glb` | `characters/player-01-match.glb` |
| Triangles | 19,358 | 7,385 |
| Meshes | 16 | 10 |
| Bones | 53 | 53 |
| Animation clips | 15 | 15 |
| Animated bones per clip | 14 | 14 |
| Size | 1.6 MB | 1.11 MB |
| Unit scale | metres | metres |
| Forward / up | `+Z` / `+Y` | `+Z` / `+Y` |
| Skin influences | 4 per vertex | 4 per vertex |
| Licence | CC0 1.0 | CC0 1.0 |

The high-detail asset keeps eye decals, eyebrows, cuffs, sock trims and boot
soles for the lab. The match LOD preserves the face decals, removes cuffs, sock
trims and boot soles, and decimates the body and garments; its material names
stay identical so the runtime team palette can replace shirt, shorts, socks and
collar without touching skin, hair, face or boots.

The lab page is `packages/client/character.html`. It loads
`packages/client/public/characters/player-01.glb`, exposes six procedural poses,
four camera presets, a skeleton overlay and a wireframe toggle. It is a
presentation-only page: it does not import `@fb/sim`.

### Rebuilding

Requirements: Blender **4.5+**, Python **3.10+** with Pillow and NumPy.

```bash
pnpm character:build
```

The command regenerates the support textures, rebuilds both the high-detail GLB
and the decimated match LOD from the MakeHuman base, and copies both into the
Vite public directory. Both GLBs embed WebP images at quality 90 and carry the
fifteen M18 animation clips. It looks for Blender on `PATH` and in the Windows
Program Files locations. Override the
executables when needed:

```bash
BLENDER_BIN=/opt/blender/blender PYTHON_BIN=python3 pnpm character:build
```

Render the inspection frames into `assets/previews/`:

```bash
pnpm character:preview
```

### Source provenance

- **Body base:** MakeHuman/MPFB anatomical base with a 53-bone game skeleton,
  repackaged by Innerscene. CC0 1.0. The original is preserved at
  `assets/source/makehuman/makehuman-base.glb`; see the nearby README.
- **The generated player:** CC0 1.0 derivative. It is fictional and does not
  depict a real person or a real club.
- **Kit artwork, eye decal, hair normal, weave and pore maps:** generated by the
  scripts in `tools/` from seeded procedural data. No third-party art is
  embedded.
- **Fonts:** Barlow Condensed and Barlow, SIL Open Font License, kept under
  `assets/fonts/`.

### Rig contract

The bone names are the MakeHuman game skeleton (`root`, `pelvis`, `spine_01`,
`spine_02`, `spine_03`, `neck_01`, `head`, `clavicle_l/r`, `upperarm_l/r`,
`lowerarm_l/r`, `hand_l/r`, `thigh_l/r`, `calf_l/r`, `foot_l/r`, `toe_l/r`, plus
fingers). The viewer's pose module addresses the large joints only.

### Known art limitations

This is a clean first character pass, not a scanned likeness or a final
animation library:

- The body is an A-pose skinned mesh; the fifteen clips are baked from the
  procedural pose model rather than hand-authored by an animator. There is no
  facial rig, blend shapes or per-foot inverse kinematics; the match renderer
  applies root-level foot planting.
- The eye decal is a conforming painted surface, not modelled cornea/iris
  geometry; the eyelids and face are from the MakeHuman base.
- Garments derive from the body surface and are thickened with a solidify
  shell. The shorts read tighter than a real match short, and the collar is a
  simple smooth band rather than a ribbed garment with an opening placket.
- The hair is a cropped cap with a procedural normal map, not cards, clumps or a
  groom.
- Shirt numbers and crests are generated 2D atlas art, not cloth embroidery or a
  normal-mapped print. The kit is fictional and the palette is fixed.
- The asset uses embedded WebP images at quality 90. A shipping GPU path should
  move the normal and colour maps to KTX2/Basis and add meshopt/Draco geometry
  compression.
