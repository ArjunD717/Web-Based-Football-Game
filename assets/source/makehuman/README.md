# MakeHuman/MPFB anatomical base

`makehuman-base.glb` is a CC0 anatomical base mesh with a 53-bone game skeleton,
derived from MakeHuman/MPFB assets and repackaged by Innerscene.

- Source: https://www.innerscene.com/tools/library/3d-parts/human-base-mesh-with-editable-53-bone-rig-8e7c8ab1
- Upstream: https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html
- Licence: CC0 1.0 (MakeHuman/MPFB bundled assets and output)
- Downloaded: 2026-11-05
- Measured: 107,024 triangles, 70,985 vertices, 53 joints, no animation

The generated player in `assets/characters/` is a derivative and remains CC0.
