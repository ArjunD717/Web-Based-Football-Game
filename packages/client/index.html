LAN setup

How to connect

Host and guest must be on the same network. The host terminal serves HTTPS; both devices need the local certificate trusted.

  1. On the host machine, run pnpm start and open the printed HTTPS address.
  2. Create a room. The next screen shows a four-letter code and a QR code.
  3. On the second device, open the same host address, choose LAN Match, then enter the code or scan the QR.

Phone controller: open the printed controller URL on the second device if you want touch input instead of a gamepad.
